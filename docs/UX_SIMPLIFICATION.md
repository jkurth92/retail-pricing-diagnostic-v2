# UX Simplification (Step 12)

## Principles

- **Guided workflow** over internal architecture
- **Narrative-first** over mechanics-first
- **Progressive disclosure** for evidence, assumptions, and reference material
- **Strategic language** in default UI copy

## What changed

- Nine workflow steps → **five pilot steps**
- Sidebar groups removed → single linear journey
- Unified upload zone (1–2 files) instead of file-type-specific intake
- Retailer onboarding centered on search + auto-profile
- Diagnostic gated behind explicit CTA
- Refine diagnostic placeholder for Step 13

## Language replacements

| Avoid in default UI | Prefer |
|---------------------|--------|
| Ontology | Reference definitions (disclosed only) |
| Inference registry | Pricing assumptions |
| Role inference | Category roles / role structure |
| Calibration engine | (hidden from client UI) |
| Signal grouping | Supporting evidence |

## What remains intentionally visible to consultants

Expandable sections for assumptions, peers, supporting evidence, and export storyline structure.
