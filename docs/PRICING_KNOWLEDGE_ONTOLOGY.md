# Pricing Knowledge Ontology

## Purpose

The knowledge registry is the **structured intelligence framework** between normalized data (Step 3–4) and future interpretive rules. It is pre-rules and pre-opportunity.

## Layers

| Layer | Role | Active in Step 5B? |
|-------|------|-------------------|
| Retailer archetypes | Expected structures by format | Yes (selection + display) |
| Pricing postures | EDLP, HiLo, Hybrid, etc. | Yes (selection) |
| Category / item roles | Strategic roles, not SKU management | Yes (ontology + inference) |
| Benchmark concepts | Descriptive families | Yes (catalog only) |
| Future rule candidates | Scaffold for later rules | Yes (status only) |
| Pattern features | Measurable descriptors | Linked by ID, not computed |
