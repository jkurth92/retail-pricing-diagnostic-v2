# Pilot Workflow

Step 12 reduces the visible journey to **five guided steps** aligned with a first retailer walkthrough.

## Steps

| # | Step | Purpose |
|---|------|---------|
| 1 | **Retailer context** | Search retailer → auto-enriched profile → light edits |
| 2 | **Upload & scope** | 1–2 files, inferred readiness, confirm categories & revenue |
| 3 | **Pricing diagnostic** | Intentional **Generate pricing diagnostic** → executive summary, themes, implications |
| 4 | **Opportunity overview** | Directional margin opportunity |
| 5 | **Executive outputs** | Email, memo, deck drafts |

## Run diagnostic gate

Engines do not surface readout content until the user runs the assessment from **Upload & scope** (or step 3 if returning). This preserves an intentional, high-value transition.

## Pilot demo

**Start pilot demo** loads `PILOT_DEMO_PRESET` (Target-style mass hybrid) for workflow and narrative review without a live upload.

## Hidden complexity

Internal validation, multi-file ingestion matrices, and framework reference material remain in the codebase but are not part of the default navigation.
