# Guided Diagnostic Experience

The product should feel like an **intelligent strategic pricing copilot** — not framework software, ontology tooling, or an analytics dashboard.

## Intended user flow

1. Type retailer
2. Review enriched profile
3. Upload files (lightweight)
4. Confirm scope
5. **Generate pricing diagnostic**
6. Review storyline (summary → themes → implications)
7. Refine (placeholder — Step 13)
8. Export outputs

## Progressive disclosure

**Primary:** executive summary, structural themes, opportunity, implications.

**Secondary (expand):** supporting evidence, confidence, role assumptions, opportunity rationale, architecture detail.

**Tertiary:** reference definitions, internal validation (not in default nav).

## Onboarding feel

Retailer step should feel **low-effort and intelligent**: enrichment, suggested posture/archetype, profile summary — with optional assumption edits behind a single disclosure.

## Upload feel

One drop zone, automatic inference messaging, scope confirmation only — no operational file taxonomy in the default path.

## Diagnostic feel

Sparse, executive-ready narrative blocks with whitespace. No engine version, calibration notes, or implementation labels in primary views.

## Step 13 preparation

`RefineDiagnosticPlaceholder` scaffolds feedback text, opportunity aggressiveness, architecture emphasis, and confidence sliders — disabled until human-in-the-loop refinement is implemented.
