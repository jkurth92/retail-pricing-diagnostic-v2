# Normative Structure Logic (Step 14B)

## Core question

> Is the retailer’s regular-price structure **coherent** relative to its positioning and category mix?

Not: “Did the retailer fail a benchmark threshold?”

## Normative inputs

1. **Retailer archetype** — discount, mass, grocery, premium grocery, specialty, convenience, club, apparel
2. **Pricing posture** — EDLP, Hi-Lo, hybrid, premium, value, convenience, specialty
3. **Category sensitivity** — grocery, household essentials, beauty, pet, apparel, electronics, home decor, seasonal
4. **Maturity (EPR proxy)** — same structural gap is more problematic at higher maturity

## Expected structure dimensions (v1)

- KVI revenue concentration band
- Premium vs mainstream gap
- Private label vs national brand gap
- Entry vs mainstream gap
- Tier spacing / compression flags

## Archetype notes (examples)

| Archetype | Structural emphasis |
|-----------|---------------------|
| Discount | Aggressive KVI, narrow architecture, visible value |
| Mass | Balanced architecture, mixed KVI + monetization |
| Grocery | KVI discipline, traffic-driver categories |
| Premium grocery | Wide premium ladders, lower KVI intensity |
| Specialty | Brand architecture and monetization critical |

## Posture modifiers

Posture **shifts** expected bands softly (e.g. Hi-Lo → slightly wider gaps; EDLP → tighter ladders). These are **not** hard rules.

## Outputs

`NormativeStructureSnapshot` — coherence question, archetype/posture notes, expected ranges used by contextual interpretation.
