# Evidence-First Philosophy (Step 13)

## Principle

**Measure → signal → hypothesis → narrative.**

Narratives should cite observable structure. Unsupported themes are suppressed rather than padded with generic consulting language.

## Executive output shape

1. **Opportunity headline** — bounded thematic margin range; wording tightens when evidence is strong
2. **Primary drivers** — architecture, PL/NB, KVI, category mix (from measured metrics)
3. **2–3 evidence-backed structural themes** — category-specific where scope allows
4. **Supporting evidence metrics** — short bullets (e.g. gap %, PL/NB categories below range)
5. **One strategic implication sentence** — interpretive, non-prescriptive

Longer narrative context and pattern inventory live behind **progressive disclosure**.

## Architecture dominance

For the current POC, architecture, KVI, and PL/NB structure drive the storyline. Promo and markdown remain secondary and optional.

## What remains placeholder

- Real client CSV parsing and SKU-level prices (rows are deterministic synthetic proxies)
- Pattern feature **values** in the inventory panel (definitions only)
- Rule engine, thresholds, and dollar opportunity formulas
- Optimization, elasticity engines, competitor matching, automated pricing actions

## Trust

Opportunity ranges are thematic and overlap-adjusted. Strong evidence narrows calibration multipliers slightly; weak evidence widens uncertainty — without implying exact optimization or false precision.
